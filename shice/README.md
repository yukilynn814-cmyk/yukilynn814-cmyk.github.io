# 食策 · 免费开源饮食助手

浅色主题的饮食管理 + 推荐工具。帮你「决定」吃什么，而不是随机糊弄。

## 功能

### 精准控制（向导式）
按 5 步筛选：**热量 → 主食 → 口味 → 口感 → 就餐方式**。每一步都能用「上一步」返回修改。

- 选 **堂食** → 按条件给「搭配推荐 + 命中理由 + 备选」，按匹配度排序（不是随机）
- 选 **外卖** → 定位 + 搜索附近餐饮店，符合筛选的置顶

### 随机模式
早 / 午 / 晚 / 夜宵四个餐段，逐餐抽取，每餐数据保留，底部显示「全天合计」和「重新选一天」。

### 热量明细
每道菜都拆成「建议份量 + 大卡」，推荐结果里直接列出：
米饭 150g·174 大卡、豆浆 250ml·75 大卡 …

### 饮品 / 汤品
13 种常见饮料（可乐 330ml·139、雪碧 500ml·200、无糖茶·0 …）+ 9 种汤品（紫菜蛋花汤·40、排骨汤·150 …）。
**「不需要饮品 / 不需要汤」默认选中 = 0 大卡**。

### 总热量与评级
底部总结面板实时汇总：总热量 + 评级
**≤500 低脂 Low-fat / 501-750 正常 Normal / >750 高卡 High-calorie**

### 按天保存记录
随机和手动两种模式的记录都存下来（按日期分组），可回看昨天吃了多少，可删单条或删整天。

## 怎么用

1. **直接双击 `index.html`** 就能在浏览器里打开（无需安装任何东西）
2. 手机 / 电脑都能用；手机浏览器可「添加到主屏幕」变成类 App

## 实拍风格图片

`assets/img/` 下共 63 张图片，统一风格：浅灰背景、自然光、真实分量，统一压缩到 512px JPEG（约 1.9MB）。

| 前缀 | 数量 | 用途 |
|---|---|---|
| `st_` | 9 | 主食照片（米饭 / 馒头 / 大饼 / 面条 / 饺子 / 面包片 / 汉堡 / 包子 / 不吃主食） |
| `d_` | 40 | 40 道菜品照片（推荐结果大图、备选缩略图、随机模式抽卡图） |
| `w_` | 14 | 向导五步的选项照片（热量 3 + 辣度 4 + 口感 5 + 就餐方式 2） |

向导的每一步都用实拍照片展示选项，用户能直接看到「低卡」长什么样、「特辣」红到什么程度。

图片由 AI 绘图模型生成（`grok-imagine-image` / `grok-imagine-image-quality` / `wan2.6-t2i`），
**属于程序生成内容，不是实拍照片**，用于帮助用户直观判断食物种类和份量，不同做法会有差异。

### 重新生成图片

```bash
# 需要环境变量 ROUTERCODE_API_KEY
python scripts/gen_food_images.py
```
脚本按 `STAPLES` / `DISHES` 里的描述批量出图，生成到 `assets/img/`，已存在的文件会跳过。

## 接入高德地图（外卖真实定位 + 真实店铺）

需要你自己的免费 Key：

1. 打开高德开放平台：https://lbs.amap.com
2. 注册登录 → 控制台 → 应用管理 → 创建新应用 → 添加 Key，**服务平台选「Web服务」**
3. 复制生成的 Key

拿到后二选一：
- **方式 A（不改代码）**：打开 App → 点右上角 ⚙ → 粘贴 Key → 保存
- **方式 B（改代码）**：编辑 `index.html`，把 `const AMAP_KEY = '';` 填上

> 没配 Key 时，外卖页显示「演示数据」，其余功能不受影响。

## 发布到 GitHub Pages

根目录放 `index.html` 即可，无需构建。

## 技术栈

纯 HTML + CSS + 原生 JS，零依赖、零构建、零后端。
定位用浏览器 Geolocation + 高德 IP 定位兜底，店铺搜索预留高德「周边搜索」接口位（JSONP，无跨域问题）。
